# DSA Toolkit

### From Learning DSA to Solving Problems

DSA Toolkit is a Java-based project designed to help students learn and practice **Data Structures and Algorithms** through simple, interactive programs.

The project provides implementations of commonly used DSA concepts in one place, making it easier to understand how different data structures and algorithms work.

## 🚀 Features

- Arrays
- Searching
- Sorting
- Recursion
- Linked List
- Stack
- Queue
- Basic DSA Practice
- Menu-driven Java program
- Simple and beginner-friendly implementation

## 🛠️ Technologies Used

- **Java**
- **Data Structures & Algorithms**
- **Object-Oriented Programming**
- **Git & GitHub**

## 📚 Topics Covered

### Arrays
Basic array operations and problems.

### Searching
- Linear Search
- Binary Search

### Sorting
- Bubble Sort
- Selection Sort
- Insertion Sort
- Other basic sorting concepts

### Recursion
Basic recursive problems and examples.

### Linked List
Implementation and basic operations of a singly linked list.

### Stack & Queue
Implementation and basic operations of stack and queue.

## ▶️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/shaurabh2003/DSA-TOPIC-CODES.git
```

### 2. Open the project

Open the project folder in **VS Code**, IntelliJ IDEA, Eclipse, or any Java-supported IDE.

### 3. Compile the Java file

```bash
javac DsaToolkit.java
```

### 4. Run the program

```bash
java DsaToolkit
```
